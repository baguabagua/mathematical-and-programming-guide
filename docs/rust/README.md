# Rust

这里介绍 Rust 编程语言的相关知识。

Rust 是我非常喜欢的一门编程语言，核心特性是内存安全、高性能和并发安全。写起来的体验也很爽快。

假定读者具有一定程度的其它语言的基础。

可以优先参考官方的教程，在 https://doc.rust-lang.org/stable/ 中。这里特别推荐其中一些：

1. [The Rust Programming Language](https://doc.rust-lang.org/stable/book/index.html) 适合初学者。前六章比较基础，推荐看过去。再往后的部分编排顺序不一定合理。如果看我的教程，完全不看也是可以的。不过我的进度可能不快而且会遗漏一些东西。
2. [Rust By Example](https://doc.rust-lang.org/stable/rust-by-example/index.html) 适合对各种概念有了解，但是没有记熟，想快速查阅写法的情况。
3. [Rustlings](https://github.com/rust-lang/rustlings) 修正语法错误的闯关小游戏。可以在学习 Rust 的过程中配套使用。
4. [The Cargo Book](https://doc.rust-lang.org/stable/cargo/index.html) 对 Rust 的包管理工具 Cargo 的介绍。适合对基础语法熟悉后，想了解项目管理时看。
5. [Tokio Tutorial](https://tokio.rs/tokio/tutorial) Tokio 是 Rust 实践上的异步运行时标准。这份指南提供了对 Rust 异步和 Tokio 的基本介绍。需要了解异步时优先看。
