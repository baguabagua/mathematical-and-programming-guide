# 函数

> 简单介绍 Rust 的函数。

前面已经见过一些函数的例子。这里直接给出一般的语法：

```rust
fn [函数名]([参数列表]) -> [返回值类型] {
    // 函数体
}
```

示例：

```rust
fn add(x: i32, y: i32) -> i32 {
    x + y
}

fn min(x: i32, y: i32) -> i32 {
    if x < y { x } else { y }
}
```

参数列表可以换行，这在参数很多，参数名/参数类型很长的时候有用。

```rust
fn complex_function(
    argument1: Type1,
    argument2: Type2,
    argument3: Type3,   // 最后一个参数后加不加逗号都行，一般行内不加，多行加
) -> ReturnType {
    // ...
}
```

也支持用 return 提前返回。例如：

```rust
fn leap_year(year: i32) -> bool {
    if year % 4 != 0 {
        return false;
    }
    if year % 100 != 0 {
        return true;
    }
    if year % 400 != 0 {
        return false;
    }
    return true; // 这里直接写 true 也行
}
```

可以没有返回值，相当于返回值类型是 `()`。

函数的参数默认是不可变的，但是也可以加上 `mut` 使其可变。可以把参数列表看成是声明了一些变量。例如：

```rust
fn add_one(mut n: i32) -> i32 {
    n += 1;
    n
}
```

和 C/C++ 一样，对参数的操作不会影响到调用参数的地方。也就是说，下面例子中的函数并不能交换两个变量的值。

```rust
fn swap(mut x: i32, mut y: i32) {
    (x, y) = (y, x);
}
swap(x, y); // 实际上并不能起到交换变量的作用
```

如果真的想交换，C/C++ 是用指针或引用来解决的，Rust 也有引用和借用的概念。我们后面再详述。
