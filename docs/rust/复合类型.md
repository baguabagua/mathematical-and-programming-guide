# 复合类型

> 介绍 Rust 的元组、数组、Vec、结构体、枚举。

## 元组（Tuple）

元组在我们之前的示例中已经多次出现过了。它就是把多个值放到一起产生的类型，这多个值的类型可以相同也可以不同。把多个类型放到一起，用逗号隔开并用小括号包裹，得到的就是元组类型，例如 `(i32, f64, u8)`. 把多个值放到一起，得到的就是元组类型的值。另外，元组可以灵活地构造或解构。例如：

```rust
let tup: (i32, f64, u8) = (50, 6.4, 1);
let (x, y, z) = tup;
let (a, (b, c)): (char, (f32, u32)) = ('A', (2.5, 3));
let t = ((a, b), c);
let (d, e) = t;
let ((f, g), h) = (d, e);
```

另外，元组也支持通过 `.` 访问内部元素。例如：

```rust
let tup: (i32, f64, u8) = (50, 6.4, 1);
let t: ((char, f32), u32) = (('A', 2.5), 3);
println!("{} {} {} {}", tup.0, tup.1, tup.2, t.0.0); // 50 6.4 1 A
```

元组也可以放到函数参数中，或者作为函数的返回值类型。作为函数参数时，可以直接写成绑定或者没有绑定的形式：

```rust
fn add(coord1: (f32, f32), coord2: (f32, f32)) -> (f32, f32) {
    (coord1.0 + coord2.0, coord1.1 + coord2.1)
}
fn sub((x1, y1): (f32, f32), (x2, y2): (f32, f32)) -> (f32, f32) {
    (x1 - x2, y1 - y2)
}
```

元组可以可变或不可变。当以元组的形式同时声明多个变量时，每个变量的可变性要单独标注。例如：

```rust
let mut tup = (50, 6.4, 1); // 可以
tup.1 = 3.2;
let (x, mut y) = (2, 3.0); // 可以
y += 0.5;
x = 3; // 编译报错：x不可变
let mut (a, b) = ('A', 28); // 编译报错：不能这样写
```

只有一个元素的元组也是存在的，但是写法上必须加上一个逗号，如果不加则不是元组。例如：

```rust
let mut x: i32 = 3;
let y: (i32) = 4; // 可以，因为 (i32) 和 i32 就是一个类型
let t: (i32,) = (5,);
x = y; // 可以
x = t; // 编译报错：类型不同
```

零个元素的元组也是存在的，就是我们之前提到过的 Unit 或者叫单元 `()`。它既是类型也是值，且这个类型的值只有一个，就是 `()`。

元组可以用 `{:?}` 直接格式化输出，这是因为元组实现了 `Debug` Trait。

```rust
let t2 = (1, 2);
println!("{:?}", t2);  // 输出: (1, 2)
println!("{}", t2);  // 编译错误
```

## 数组（Array）

数组是把多个相同类型的值放到一起产生的新类型。值的写法是把所有值放到一起，用逗号隔开并用小括号包裹，例如 `[1, 2, 3, 4, 5]`。类型的写法是 `[类型名; 数组长度]`，例如 `[i32; 5]`。也支持用这种方式写值，但是要求内部每个值都相同，例如 `[3; 5]` 就是 `[3, 3, 3, 3, 3]`。

数组支持通过 `[]` 取出内部元素。运行时数组越界会报错。数组也可以可变或不可变。

```rust
let months = ["January", "February", "March", "April", "May", "June", "July",
              "August", "September", "October", "November", "December"];

let month1 = months[0];

let mut a = [1, 2, 3, 4, 5];

let first = a[0]; // 1
let second = a[1]; // 2
a[2] = 8; // 可以单独修改一个元素
a = [3; 5]; // 也可以整体修改。注意修改变量不能改变变量的类型
```

数组可以通过 `for` 遍历。

```rust
let arr = [1, 2, 3, 4, 5];
for item in arr {
    println!("{}", item);
}

// 也可以获取索引，会在介绍迭代器时更详细地介绍
for (i, item) in arr.iter().enumerate() {
    println!("arr[{}] = {}", i, item);
}

// 可变遍历，涉及引用
let mut mut_arr = [1, 2, 3];
for item in &mut mut_arr {
    *item *= 2;
}
```

数组也可以用 `{:?}` 直接格式化输出，这是因为数组也实现了 `Debug` Trait。

```rust
let arr = [1, 2, 3];
println!("{:?}", arr);  // 输出: [1, 2, 3]
println!("{}", arr);  // 编译错误
```

高维数组可以通过低维数组嵌套实现，例如 `[[i32; 5]; 8]`。

数组的长度是不可变的。如果需要可变长度的数组，需要用到 `Vec`，类似 `c++` 中的 `vector`。

## Vec

`Vec` 就是动态数组。类型的写法是 `Vec<类型名>`。同样可以通过 `[]` 取出内部，通过 `for` 遍历，通过 `{:?}` 格式化输出。下面的示例展示了一些常见用法：

```rust
// 创建 Vec
let mut v1: Vec<i32> = Vec::new();        // 通过 new
v1.push(1);
v1.push(2);

let v2 = vec![1, 2, 3];                  // 通过 vec! 宏
let v3 = Vec::from([1, 2, 3]);           // 通过 from

// 通过 [] 索引访问
let first = v2[0];                       // 1

// 通过 for 遍历
for item in &v2 {
    println!("{}", item);
}

// 格式化输出
println!("{:?}", v2);                    // 输出: [1, 2, 3]

// 常用操作
let mut v = vec![1, 2, 3, 4, 5];
v.push(6);                               // 末尾添加
v.pop();                                 // 弹出末尾元素，返回 Some(6)
v.insert(2, 10);                         // 在索引 2 处插入 10
v.remove(0);                             // 移除索引 0 处的元素
let len = v.len();                       // 长度
v.contains(&3);                          // 判断是否包含 3
v.clear();                               // 清空
```

更多深入的对 `Vec` 的操作与迭代器 `Iterator` 有关。我们会在将来介绍。

## 结构体（Struct）

结构体中可以有零个或多个不同类型的成员。只有一个成员时，可以简写成元组的形式，称为元组结构体。

```rust
struct User {
    active: bool,
    username: String,
    email: String,
    sign_in_count: u64, // 最后一项加不加逗号都行，推荐加
} // 不用加分号，加了会警告
struct ChessBoard([[Grid; 8]; 8]); // 只有一个成员，这种写法必须加分号，不加会报错
struct Color(i32, i32, i32);    // 只有一个元组成员的情况
struct Point(i32, i32, i32);
struct Unit;    // 没有成员，等价地也可以写 struct Unit {} 或 struct Unit();
```

创建结构体类型的值：

```rust
fn main() {
    let user1 = User {
        active: true,
        username: String::from("someusername123"),
        email: String::from("someone@example.com"),
        sign_in_count: 1,
    };

    // 如果新的结构体和另一个结构体的部分成员相等，则可以这样省略相等的成员
    let user2 = User {
        email: String::from("another@example.com"),
        ..user1
    };

    let board = ChessBoard([[Grid::new(); 8]; 8]);
    let black = Color(0, 0, 0);
    let origin = Point(0, 0, 0);
    let unit = Unit;
}
// 如果有和成员同名的变量，则可以在创建结构体时简写
fn build_user(email: String, username: String) -> User {
    User {
        active: true,
        username,
        email,
        sign_in_count: 1,
    }
}
```

通过 `.` 访问成员，元组结构体的话通过 `.0, .1`：
```rust
let name = user1.username;
let board = board.0;
let (r, g, b) = (black.0, black.1, black.2);
let Color(r, g, b) = black; // 元组结构体也可以这样解构
```

## 枚举（Enum）

枚举类型表示一个值可能是多个类型之一。例如，如果你已经有了三个类型 `Rectangle`, `Triangle`, `Circle`，现在想用一个新类型表示形状，可以这么写：

```rust
enum Shape {
    Rect(Rectangle),
    Tria(Triangle),
    Circ(Circle), // 最后一项加不加逗号都行，推荐加
} // 不用加分号，加了会警告
```

直接支持元组类型。例如：

```rust
enum Color {
    Rgb(u8, u8, u8),
    Rgba(u8, u8, u8, u8),
}
```

也支持类似结构体的写法：

```rust
enum AnotherColor {
    Rgb { red: f32, green: f32, blue: f32 },
    Rgba {
        red: f32,
        green: f32,
        blue: f32,
        alpha: f32, 
    },
}
```

也有可能只是多个值之一。这种用法比较接近 C++ 的枚举：

```rust
enum ChessPiece {
    King,   // 相当于 King(),
    Queen,
    Knight,
    Rook,
    Bishop,
    Pawn,
}
```

创建枚举：

```rust
let rect: Rectangle = Rectangle::new(); // 先假设这里有一个 Rectangle 类型的值 rect
let shape: Shape = Shape::Rect(rect);      // 可以这样创建 Shape，当然类型标注不是必须加的
let black: Color = Color::Rgb(0, 0, 0);
let my_color = AnotherColor::Rgb{ red: 0.2, green: 0.1, blue: 0.6 };
let piece = ChessPiece::King;
```

使用枚举时一般要用 `match` 模式匹配：

```rust
fn area(shape: Shape) -> f32 {
    match shape {
        Shape::Rect(r) => r.area(),
        Shape::Tria(t) => t.area(),
        Shape::Circ(c) => c.area(),
    }
}
```

也可以解构其它写法：

```rust
match Color {
    Color::Rgb(r, g, b) => {},  // 这里 r: u8, g: u8, b: u8
    Color::Rgba(rgba) => {},    // 这里 rgba: (u8, u8, u8, u8)
}
match AnotherColor {
    AnotherColor::Rgb{ r: red, g: green, b: blue } => {},
    AnotherColor::Rgba{ red, green, blue, alpha } => {},  // 如果有和成员同名的变量，则可以简写
}
let is_king = match ChessPiece {
    ChessPiece::King => true,
    _ => false,
};
```

注意 `match` 的分支必须覆盖所有可能的值，否则会报错。可以用通配符 `_` 来覆盖剩余情况。

另外还有 `if let`, `while let` 和 `let else` 这三种处理枚举的语法，我们在后续章节讲解。

## 代数数据类型

一个类型就是一个集合，集合内的所有元素是这个类型的所有可能值。例如 `bool` = {`true`, `false`}。

创建新的类型就是构造新的集合。这里关心两种创建新类型的方式：新类型是多种旧类型中的恰好一种；或新类型中包含了多种旧类型。这样构建出的两类类型分别称为**和类型**和**积类型**。例如，`Enum` 就是和类型，而元组和 `Struct` 都是积类型。

和类型对应的集合操作是无交并，也称为带标签的并（tagged union）。例如，有两个集合 $A = \{x, y\}, B = \{y, z\}$，则它们的无交并是

$$
    A\oplus B = \{x_A, y_A, y_B, z_B\}
$$ 

多个集合可以类似定义。和的关系对集合的范数（大小）也成立，即 `|A\oplus B| = |A|+|B|`。

积类型对应的集合操作是笛卡尔积。从两个集合各取一个元素构成二元组，所有这样的二元组构成的集合就称为两个集合的笛卡尔积。即

$$
    A\times B = \{(a, b): a\in A, b\in B\}
$$

多个集合可以类似定义。乘积关系对集合的范数也成立，即 `|A\times B| = |A|\times |B|`。

可以发现，枚举其实就是和类型，而元组和结构体都是积类型。

之前多次提到过单元（Unit）类型 `()`，我们说过它是 0 个元素的元组，也是 C/C++ 中的 void 类型。是时候把它彻底讲清楚了。我们考虑这个类型对应的集合大小，发现它只能是 1，也就是说这个类型里只有一个值。这个值我们也知道，就是 `()`。

> 这里说“只能是 1” 指的是在“自然”的意义上。例如 0 的阶乘只能是 1，这是为了保持阶乘的性质 $n!\cdot (n+1) = (n+1)!$ 可以做的唯一选择。类似地，0 个数字的乘积只能是 1，因为我们要保持乘积的性质：$n+1$ 个数字的乘积必须等于 $n$ 个数字的乘积乘上最后一个数字得到的结果。
>
> `()` 又指类型又指值，这是符号上的巧合。我们可以规定元组类型用圆括号，而元组的值用另一种括号（例如 `{3, 2.5, 'A'}: (i32, f32, char)`），这样就很容易看出单元作为类型和值其实是两个不一样的东西。不过一般通过上下文（语境）就足以区分它们了，或者就是语境中没必要区分二者。

为什么说无返回值其实就是返回单元？出于自然的目的，我们希望所有的表达式或函数都有返回值类型，而且运行结束时要返回一个该类型的值。此时无返回值其实是指我们不关心返回值，只有一个值的类型正好满足这样的考虑。

单元类型是类型乘积操作的单位元。类似地，会考虑类型求和操作的单位元。考虑这个类型对应的集合大小，发现它只能是 0. 这个类型在 Rust 中写作 `!`，可以将它称作无（never type）。一般不会直接定义这个类型的变量，不过它仍然是有用的，表示永远不会返回值。我们之前说过 if-else 或 match 的各分支返回值类型必须相同，但其实不完全是这样，允许有一些分支返回 `!`。例如：

```rust
fn foo(x: i32) -> String {
    let y = match x {   // 这里可以推断出 y 的类型是 &'static str
        0 => "zero",
        1 | 2 => "one or two",           
        3..=7 => "between three and seven", // 上面三种情况表达式的类型都是 &'static str
        _ => return String::from("something else"), // 这里表达式的类型是 !, 因为永远都不会从这里返回上一级
    };
    format!("number {}", y)
}
```

> 了解 `!` 类型之后更容易理解为什么 `void` 对应的是 `()` 而不是 `!`，因为 `()` 是不关心返回值，而 `!` 是永不返回。
>
> 其实多个分支返回值类型本来就可以不同，只要能把各个分支的返回值类型糅合成一种新类型就行。不过 Rust 不支持匿名的和类型，所以就只能糅合同一种类型以及 `!` 了。

## 面向对象

把 `Struct` 和 `Enum` 称为自定义类型。它们都支持一些面向对象特性，例如，数据和操作分离。可以用 `impl` 块为它们实现一些函数，称为方法，调用起来也很像面向对象语言。

```rust
struct Rectangle {
    width: f32,
    height: f32,
}
struct Circle {
    radius: f32,
}
enum Shape {
    Rect(Rectangle),
    Circ(Circle),
}
impl Rectangle {
    fn new(width: f32, height: f32) -> Self {
        Self { width, height }
    }
    fn area(&self) -> f32 {
        self.width * self.height
    }
    fn perimeter(&self) -> f32 {
        2.0 * (self.width + self.height)
    }
}
impl Circle {
    const PI: f32 = 3.14159265;
    fn new(radius: f32) -> Self {
        Self { radius }
    }
    fn area(&self) -> f32 {
        Self::PI * self.radius * self.radius
    }
    fn perimeter(&self) -> f32 {
        2.0 * Self::PI * self.radius
    }
}
impl Shape {
    fn area(&self) -> f32 {
        match self {
            Self::Rect(r) => r.area(),
            Self::Circ(c) => c.area(),
        }
    }
    fn perimeter(&self) -> f32 {
        match self {
            Self::Rect(r) => r.perimeter(),
            Self::Circ(c) => c.perimeter(),
        }
    }
}
fn main() {
    let mut shapes = Vec::new();
    shapes.push(Shape::Rect(Rectangle::new(2.8, 3.4)));
    shapes.push(Shape::Circ(Circle::new(2.5)));

    for (i, shape) in shapes.iter().enumerate() {
        println!("Area of shape {} is {}", i, shape.area());
        println!("Perimeter of shape {} is {}", i, shape.perimeter());
    }

    println!("Pi is {}", Circle::PI);
}
```

具体来说，在 `impl` 块中可以干这些事情：

- 用 `Self` 指代这个类型
- 定义常量。在块内可以用 `Self::` 访问到。在块外可以用 `类型名::` 访问到。
- 定义函数。函数可以有 `self` 参数。
  - 如果没有 `self` 参数，就像普通函数一样，在块内可以用 `Self::` 访问到。在块外可以用 `类型名::` 访问到。
  - 如果有 `self` 参数，则要用 `.` 调用，如上面的 `shape.area()`，`.` 之前的部分自动填入 `self` 参数。
  - 实际上 `self` 参数可以有多种形式：`self`, `&self`, `&mut self`。这就涉及所有权与引用。我们会在下一节讲解。
