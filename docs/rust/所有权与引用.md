# 所有权与引用

> 介绍 Rust 的所有权机制，引用与借用，以及切片。
>
> 本节内容包含大语言模型辅助写作。

## 所有权基本规则

Rust 中的每个值都有一个**所有者**（owner）。所有者是持有该值的变量。当所有者离开作用域时，这个值会被自动销毁（调用 `drop`）。

所有权规则：
1. Rust 中每个值都有一个唯一的**所有者**。
2. 同一时刻，一个值只能有一个所有者。
3. 当所有者离开作用域，值会被释放。

```rust
{
    let s = String::from("hello");  // s 是所有者
    // 使用 s
}                                   // 作用域结束，s 被 drop，内存释放
```

## 移动语义（Move）

### 赋值或传参导致所有权转移

对于非基本类型（例如 `String`, `Vec`, 自定义结构体），赋值、传参或返回值默认会发生**所有权转移**（move）。转移后，原变量不再有效，不能再使用。

```rust
// String 的例子
let s1 = String::from("hello");
let s2 = s1;            // s1 的所有权被移动到 s2
// println!("{}", s1);  // 编译错误：s1 已无效

// Vec 的例子
let v1 = vec![1, 2, 3];
let v2 = v1;            // 所有权转移
// println!("{:?}", v1); // 错误

// 自定义结构体
struct Person {
    name: String,
    age: u8,
}
let p1 = Person { name: String::from("Alice"), age: 30 };
let p2 = p1;            // 所有权转移
// println!("{}", p1.name); // 错误
```

### 函数参数转移所有权

将变量传入函数时，所有权也会转移到函数参数中。

```rust
fn take_ownership(s: String) {
    println!("{}", s);
}   // s 在此被 drop

fn main() {
    let s = String::from("world");
    take_ownership(s);
    // println!("{}", s); // 错误：s 的所有权已转移
}
```

### 函数返回值转移所有权

函数返回一个值时，所有权会从函数内部转移到调用者。

```rust
fn give_ownership() -> String {
    let s = String::from("hello");
    s   // 所有权转移给调用者
}

fn main() {
    let s = give_ownership();   // s 获得所有权
    println!("{}", s);
}
```

## 复制语义（Copy）

某些类型实现了 `Copy` trait，它们在赋值或传参时会**自动复制**，原变量仍然可用。这些类型通常是存储在栈上的简单类型。

### 哪些类型实现了 Copy？

- 整数类型（`i32`, `u32`, `isize`, `usize` 等）
- 布尔类型 `bool`
- 浮点数类型 `f32`, `f64`
- 字符类型 `char`
- 由上述类型组成的元组（如 `(i32, i32)`）
- 由上述类型组成的数组（如 `[i32; 5]`）

**注意**：`String`、`Vec` 等堆分配的类型**没有**实现 `Copy`。

```rust
// i32 是 Copy 类型
let x = 5;
let y = x;          // x 被复制，仍然可用
println!("x = {}, y = {}", x, y);

// 元组 (i32, bool) 也是 Copy
let tup = (42, true);
let tup2 = tup;     // 复制
println!("{:?} {:?}", tup, tup2);

// 包含 String 的元组则不是 Copy
let s = String::from("hello");
let tup3 = (s, 100);
let tup4 = tup3;    // 所有权转移！tup3 不再有效
// println!("{:?}", tup3); // 错误
```

### 函数参数使用 Copy 类型

```rust
fn print_number(n: i32) {
    println!("{}", n);
}   // n 是复制品，不影响原变量

fn main() {
    let num = 10;
    print_number(num);
    println!("num still usable: {}", num);  // 仍然可用
}
```

## 深拷贝：clone

对于非 `Copy` 类型，如果希望复制其堆上的数据，可以显式调用 `clone` 方法进行深拷贝。

```rust
let s1 = String::from("hello");
let s2 = s1.clone();        // 深拷贝堆数据
println!("s1 = {}, s2 = {}", s1, s2);   // 两者都有效
```

`clone` 代价较高（需要复制堆内存），应谨慎使用。当只需要读取数据而不需要所有权时，更推荐使用引用。

## 引用与借用

**引用**（reference）是一种类型，允许你访问一个值而不获取其所有权。创建引用的行为称为**借用**（borrowing）。

### 不可变引用 `&T`

通过 `&` 可以创建不可变引用。不可变引用可以同时存在多个，但只能读取数据，不能修改。

```rust
fn main() {
    let s = String::from("hello");
    let r1 = &s;        // 不可变引用
    let r2 = &s;        // 可以多个
    println!("{} {}", r1, r2);
    // s 的所有权没有被转移，仍然可以使用
}
```

使用不可变引用作为函数参数，可以避免所有权转移，同时避免复制大类型。

```rust
fn calculate_length(s: &String) -> usize {
    s.len()   // s 是引用，没有所有权，离开作用域不会释放数据
}

fn main() {
    let s = String::from("hello");
    let len = calculate_length(&s);
    println!("length of '{}' is {}", s, len);   // s 仍然有效
}
```

### 可变引用 `&mut T`

通过 `&mut` 可以创建可变引用，允许修改借用的数据。可变引用有严格的限制：

- 在同一作用域内，对同一数据只能有一个可变引用。
- 不能同时拥有可变引用和不可变引用。

```rust
fn main() {
    let mut s = String::from("hello");
    let r1 = &mut s;
    // let r2 = &mut s;   // 编译错误：不能有两个可变引用
    r1.push_str(", world");
    println!("{}", r1);
}
```

```rust
let mut s = String::from("hello");
let r1 = &s;           // 不可变引用
let r2 = &s;           // 不可变引用
// let r3 = &mut s;    // 错误：不能同时存在不可变和可变引用
println!("{} {}", r1, r2);
```

可变引用的作用域并非严格从创建到 `}` 结束，而是到该引用最后一次使用之后。Rust 的**非词法生命周期**（NLL）使得借用检查更加灵活。

```rust
let mut s = String::from("hello");
let r1 = &s;
println!("{}", r1);     // r1 最后一次使用
let r2 = &mut s;        // 可以，因为 r1 不再使用
r2.push_str(" world");
```

### 悬垂引用（Dangling Reference）

Rust 编译器会在编译时阻止悬垂引用，即引用已被释放的内存。

```rust
fn dangle() -> &String {   // 编译错误
    let s = String::from("hello");
    &s                      // 错误：s 离开作用域将被释放，返回的引用无效
}  
```

## 模式匹配与引用

### `for` 循环中的引用

默认情况下 `for item in collection` 会取得集合的所有权。使用引用遍历可以避免移动所有权。

```rust
let v = vec![1, 2, 3];
for item in &v {        // 不可变引用
    println!("{}", item);
}
// v 仍然有效

let mut v = vec![4, 5, 6];
for item in &mut v {    // 可变引用
    *item *= 2;
}
println!("{:?}", v);    // [8, 10, 12]
```

### `if let` 和 `while let` 中的引用

匹配引用时，需要使用 `&` 或 `ref` 关键字。

```rust
let opt = Some(String::from("hello"));
if let Some(ref s) = opt {
    println!("{}", s);      // s 是 &String，不会取得所有权
}
println!("{:?}", opt);      // opt 仍然有效

let mut data = Some(42);
while let Some(ref mut x) = data {
    *x += 1;
    if *x > 45 { break; }
}
```

## 切片（Slice）

**切片**是对集合中一段连续元素的引用。切片本身也是引用，不持有所有权。

### 数组切片 `&[T]`

数组切片可以引用数组或 `Vec` 的一部分，类型为 `&[T]`。

```rust
let arr = [1, 2, 3, 4, 5];
let slice = &arr[1..4];     // 引用索引 1,2,3 的元素
println!("{:?}", slice);    // [2, 3, 4]

// 切片可以作为函数参数，接受任意长度的数组片段
fn sum_of_slice(s: &[i32]) -> i32 {
    s.iter().sum()
}

let v = vec![10, 20, 30, 40];
println!("{}", sum_of_slice(&v[1..3]));   // 20+30=50
println!("{}", sum_of_slice(&arr));       // 全部，&arr 是 &[i32; 5] 自动转换为 &[i32]
```

### 字符串切片 `&str`

字符串字面量（如 `"hello"`）的类型是 `&str`，它是对程序二进制中只读字符串数据的切片。`String` 可以通过切片得到 `&str`。

```rust
let s = String::from("hello world");
let hello = &s[0..5];   // 引用前 5 个字符
let world = &s[6..11];

println!("{} {}", hello, world);
```

`&str` 作为函数参数非常灵活，可以同时接受 `String` 的引用和字符串字面量。

```rust
fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return &s[0..i];
        }
    }
    &s[..]
}

fn main() {
    let my_string = String::from("hello world");
    let word = first_word(&my_string);   // &String 自动解引用为 &str
    println!("{}", word);

    let literal = "hello world";
    let word = first_word(literal);       // &str 直接传入
    println!("{}", word);
}
```

**注意**：字符串切片需要保证索引在字符边界上（不能用字节索引切在 UTF-8 字符中间）。若不确定边界，推荐使用 `&s[..]` 或库函数。

## 总结

- 所有权是 Rust 内存安全的核心：每个值有唯一所有者，离开作用域自动释放。
- 移动语义将所有权转移，避免二次释放；`Copy` 类型自动复制。
- 引用允许借用而不取得所有权，通过 `&` 和 `&mut` 实现。
- 借用规则保证数据竞争安全：多个不可变引用，或一个可变引用。
- 切片是对连续数据段的引用，常用于高效访问数组或字符串片段。
