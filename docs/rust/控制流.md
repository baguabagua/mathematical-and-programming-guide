# 控制流

> 介绍 Rust 中的控制流，包括 if, match, while, loop, for
>
> 假定读者有其它语言的基础，最好是 C 或 C++.

## if 分支选择

语法：`if [条件] {...}` 或 `if [条件] {...} else {...}`

注意事项：
1. `[条件]` 不需要加括号。加了也不会报错，但是会有警告。
2. `[条件]` 必须是 bool 类型。通常情况下，Rust 不会自动做类型转换。
3. 花括号必须有，任何情况都不能省略。
4. Rust 中一切皆表达式，花括号最终可以返回一个值。也就是说，可以写出这样的代码：`let c = if a < b { a } else { b };` 但这只能在有两个分支的情况下使用，且两个花括号内返回的值类型必须相同。如果只有一个分支，则花括号不能返回值，可以理解为另一个花括号没有返回值，这个花括号必须与之匹配。
5. 允许 `if [条件] {...} else if [条件] {...} else {...}` 这样的嵌套使用。

## while 循环

语法：`while [条件] {...}`

注意事项：
1. `[条件]` 不需要加括号。加了也不会报错，但是会有警告。
2. `[条件]` 必须是 bool 类型。通常情况下，Rust 不会自动做类型转换。
3. 花括号必须有，任何情况都不能省略。
4. 可以用 `continue` 和 `break` 跳过本轮循环或终止循环。

## loop 循环

语法：`loop {...}`

相当于 `while true {...}`。

## for 循环

语法：`for [变量名] in [范围] {...}`

示例：

```rust
let mut sum = 0;

for i in 1..=100 {
    sum += i;
}

assert_eq!(sum, 5050);
```

注意事项：
1. Rust 不支持 C 风格的 for 循环，如有需要请用 while 循环。
2. 花括号必须有，任何情况都不能省略。
3. 可以用 `continue` 和 `break` 跳过本轮循环或终止循环。
4. `[范围]` 可以是任何实现了 `IntoIterator` trait 的类型。这在数组上更加有用。目前先记住这几种：`a..b` 左闭右开区间，`a..=b` 闭区间，`.rev()` 反转（如 `(1..=5).rev()`）。

## match 模式匹配

语法：`match [值] { [模式] => [表达式], ... }`

注意事项：

1. `match` 是表达式，可以返回值。所有分支 `=>` 后面表达式的类型必须相同。也可以所有分支都不返回值，此时什么都不做的分支表达式的位置要用 `()` 或 `{}` 占位。
2. 分支必须覆盖所有可能的值（即“穷尽性”检查）。例如匹配 `bool` 时，必须同时处理 `true` 和 `false`，否则编译错误。类似地，匹配整数时通常需要一个通配符 `_` 来覆盖剩余情况。
3. 每个分支的 `=>` 后面可以是单个表达式，也可以是用花括号包裹的代码块。
4. 模式包括单个值、范围、多模式。多个模式用 `|` 分隔。
5. 可以使用 `if` 添加匹配守卫（match guard），例如 `x if x < 0 => ...`，它允许对匹配到的值进一步条件判断。
6. Rust 的 `match` 没有“穿透”问题（不像 C 的 `switch`），匹配到第一个成功分支后立即退出，不需要 `break`。

示例：

```rust
// 匹配 bool
let b = true;
let result = match b {
    true => "yes",
    false => "no",
};
assert_eq!(result, "yes");

// 匹配整数：单个值、多个值、范围
let n = 5;
let desc = match n {
    0 => "zero",
    1 | 2 => "one or two",           // 多个模式用 | 分隔
    3..=7 => "between three and seven", // 范围匹配
    _ => "something else",           // 通配符匹配所有剩余情况
};
assert_eq!(desc, "between three and seven");

// 使用匹配守卫比较区分三种情况（正、零、负）
let x = -3;
let sign = match x {
    0 => "zero",
    _ if x > 0 => "positive",        // 守卫：当 x > 0 时匹配
    _ => "negative",                 // 此时 x < 0
};
assert_eq!(sign, "negative");
```

注意：
- 通配符 `_` 匹配所有未列出的值，在整数匹配中通常放在最后分支。
- 如果只关心特定值而忽略其他值，可以使用 `_` 作为“默认分支”。
- `match` 最主要的用法之一是配合 `enum` 类型进行解构，我们将在后续章节介绍。
