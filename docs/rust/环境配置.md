# 环境配置

先省略。可以看 [The Rust Programming Language](https://doc.rust-lang.org/stable/book/index.html) 第一章。

推荐使用 VSCode 作为代码编辑器，安装 rust-analyzer 插件。

简单总结配置好之后常用到的操作：

`cargo new [项目名]` 在当前位置新建一个项目，名称为项目名，位于 `./[项目名]/` 下。会自动在当前位置下新建 `[项目名]` 文件夹，并初始化其内部。如果当前位置已有 `[项目名]` 文件夹则会失败。

`cargo build` 编译项目。

`cargo run` 运行项目。如果有未编译的修改则会先编译。

`cargo build --release` 和 `cargo run --release` 编译和运行项目的 release 版本（或者叫发行版本）。默认的选项（即不加 `--release`）时处理的都是 debug 版本（或者叫测试版本）。debug 版本会携带更多报错相关信息，编译速度较快，运行速度较慢。release 版本编译速度较慢，运行速度较快。如果不是对性能有要求的场合，也不是要发布的情况，可以优先用 debug 版本。

一般的项目结构：

```
└─[项目名]
   ├─Cargo.toml
   ├─Cargo.lock
   ├─src
   │  └─main.rs
   └─target
```

其中 `Cargo.toml` 是配置文件，存储项目的各种配置，初学者接触到最主要的是依赖项 `[dependencies]`。`Cargo.lock` 是自动生成的文件，存储依赖项（包括依赖的依赖）的具体版本，不应当手动编辑。

`src` 是源代码文件夹。对于二进制项目，其中一定要有 `main.rs` 表示程序入口。对于库项目，入口是 `lib.rs`。

`target` 文件夹存放编译产物。
