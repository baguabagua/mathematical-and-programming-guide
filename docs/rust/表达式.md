# 表达式

> 介绍 Rust 中一切皆表达式的思想。

C/C++ 中，表达式加上分号就成了语句，`if`, `while`, `for` 等控制流也都是语句，语句结合在一起构成代码块 `{...}`，进而实现各种功能。

Rust 中，`if`, `while`, `for` 等控制流以及代码块 `{...}` 都是表达式。也就是说，它们都可以返回值。语句是不返回值的。

Rust 中表达式后加上分号就成了语句。语句不是表达式。

特别地，控制流表达式如果没有返回值，或者说返回值的类型是 `()`，那么可以不用加分号。注意其它表达式不能这样，例如即使是调用无返回值的函数，后面也是必须加分号的。

上一小节控制流中已经见过了 `if` 和 `match` 作为表达式的例子。这里介绍其余的情况。

## 代码块

代码块由花括号 `{}` 包裹。其中可以包含任意多个语句以及最多一个表达式。如果块以表达式结尾，则该表达式的值就是整个代码块的返回值。例如：

```rust
let number = {
    let x = 3;
    let y = 4;
    x + y
};
```

函数的函数体也是代码块。

```rust
fn add(x: i32, y: i32) -> i32 {
    x + y
}

fn min(x: i32, y: i32) -> i32 {
    if x < y { x } else { y }
}
```

如果块不以表达式结尾，也就是块内都是语句，则代码块的返回值是 `()`（Unit，单元）。可以将其理解为 C/C++ 中的 void。概念上和没有返回值有点接近，但不完全一样。它和无返回值的区别会在后续章节讨论。

## loop 循环

loop 循环可以通过 `break value;` 返回值。例如：

```rust
// 假设 rand() 返回 [-1, 1] 内均匀随机实数
// 通过拒绝采样在单位圆内均匀随机取点
let (x, y) = loop {
    let (x, y) = (rand(), rand());
    if x * x + y * y <= 1 {
        break (x, y);
    }
};
```

loop 循环里可以由多个 `break` 语句，但必须保证它们返回的值类型都相同。特别的，没有加参数的 `break;` 相当于 `break ();`，而 `()` 与所有其它类型都不同。

while 和 for 循环一般不用于返回值。这是因为它们有可能通过 `break` 跳出循环，也有可能循环条件不满足而退出循环。对于后一种情况，没有加返回值的位置，默认就是返回 `()`，所以 `break` 语句也不能加其它类型的返回值。

## 什么不是表达式

`let` 语句也不是表达式。`let` 语句是必须有分号的。函数、结构体等定义也不是表达式。

尽管如此，Rust 中绝大多数东西都是表达式，都有返回值。这为写代码提供了很多便利。
