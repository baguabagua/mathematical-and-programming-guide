# 负数

> 介绍负数。
> 
> 本节内容包含大语言模型的辅助创作。

## 为什么需要比 0 更小的数

自然数、分数、小数都只表示“有多少”或“第几个”。它们有一个共同点：**都不小于 0**。但生活中常常遇到“比 0 还要少”的情形：

- **欠债**：你有 5 元钱，花掉 3 元后剩下 2 元；但如果别人借给你 7 元，你还了 5 元，那你还欠 2 元。这个“欠 2 元”就是比 0 小的数。
- **温度**：摄氏温度下，水会结冰的 0℃ 并不是“没有温度”，而是一个参考点。冬天有时 -5℃、-10℃，比 0℃ 更低。
- **海拔**：海平面为 0 米，低于海平面的地方如死海是 -430 米。
- **楼层**：地面为 0 层（或 1 层），地下停车场是 -1 层、-2 层。
- **方向**：向右走为正，向左走为负；前进为正，后退为负。

这些例子中，0 不再是“没有”，而是一个**分界点**。需要用一种新的数来表示“分界线的另一侧”。

> 楼层跟别的例子有点区别。它是编号上的负数，更像是序数的推广。

### 一个更强的动机：统一规则

如果只用正数，很多问题需要分情况讨论。例如物理中的匀变速运动：

- 速度从 10 m/s 减到 5 m/s，加速度为负；但减到 0 之后如果继续减速（即反向加速），就变成了“负速度”。若只用正数，你必须单独处理“减速到 0 后反向”这一阶段，写两个公式。
- 引入负数后，速度可以为负，加速度也可以为负。整个运动用一个公式 $v = v_0 + at$ 就能描述，无论物体是向前、向后、还是先向前再向后。**不需要分类讨论，因为正负号自动携带了方向信息。**

类似地，在记账中，收入记为正，支出记为负。结余就是直接相加（正数加负数）。不用再写“先加收入，再减去支出”两句话。统一规则让表达更简洁。

> 数学家追求的统一性在负数这里体现得很充分：**一个规则胜过一堆特例**。

## 负数的表示与数轴

在正数前面加上负号“-”就得到负数，例如 -3 读作“负三”。正数可以带正号“+”，但通常省略不写（例如 3 就表示 +3）。

> 符号“-”有两个含义：一是表示“负数”的标志（如 -3 是一个数），二是表示“减法”运算（如 5 - 3）。上下文一般能区分。如果两个负号连续出现（如 5 - (-3)），则中间用括号隔开。

为了直观地理解负数，引入**数轴**：

- 画一条直线，取一点为原点 0。
- 规定向右为正方向，那么原点右侧的点对应正数（1, 2, 3, …），左侧的点对应负数（-1, -2, -3, …）。
- 数轴上的每个点都唯一对应一个实数，每个实数也唯一对应一个点。

> 其实还没有介绍过实数是什么。先用与数轴一一对应来直观感受吧。

**相反数**：一个数 a 的相反数是 -a，它在数轴上关于原点对称。例如 3 的相反数是 -3，-5 的相反数是 5。0 的相反数是 0。

数轴上的顺序：**越往右数越大**。所以：
- 任何正数 > 0 > 任何负数。
- 例如 -5 < -3 < 0 < 2 < 5。

## 绝对值

一个数到原点的距离称为它的**绝对值**，记作 $|a|$。例如 $|-3| = 3$，$|3| = 3$，$|0| = 0$。

绝对值总是非负的。它去掉了符号，只保留大小。

**比较负数**：绝对值越大的负数反而越小。例如 -5 和 -3：$|-5| = 5$，$|-3| = 3$，$5 > 3$，但 $-5 < -3$。可以这样理解：欠 5 元比欠 3 元更“穷”。

两个数的距离可以用这两个数差的绝对值衡量。$|a-b|$ 就是 $a$ 与 $b$ 的距离。

## 负数的四则运算

负数参与运算时，规则可以统一为正数运算的推广。最关键的一条原则是：**减去一个数等于加上它的相反数**。利用这条，减法可以转化为加法，从而统一处理。

### 加法

在数轴上，加法对应移动：向右移动一个正数，向左移动一个负数。

- $3 + 2 = 5$：从 3 向右移动 2 格。
- $3 + (-2) = 1$：从 3 向左移动 2 格。
- $(-3) + (-2) = -5$：从 -3 向左移动 2 格。
- $(-3) + 2 = -1$：从 -3 向右移动 2 格。

规律：同号相加，取相同符号，绝对值相加；异号相加，取绝对值较大的符号，绝对值相减（大减小）。不必硬背，用数轴或“正负抵消”更容易。

> **抵消思想**：+1 和 -1 可以配对消掉。例如计算 $5 + (-3) = 2$，可以看作 5 中拿出 3 和 -3 抵消，剩下 2。

### 减法

利用规则：**减去一个数等于加上它的相反数**。

- $5 - 3 = 5 + (-3) = 2$。
- $5 - (-3) = 5 + 3 = 8$。
- $(-5) - 3 = (-5) + (-3) = -8$。
- $(-5) - (-3) = (-5) + 3 = -2$。

这样减法全部转化为加法，不用背“减负等于加正”等口诀。

### 乘法与除法

规则很简单：**同号得正，异号得负，再将绝对值相乘（或相除）**。

- $3 \times 2 = 6$（正正得正）
- $(-3) \times (-2) = 6$（负负得正）
- $(-3) \times 2 = -6$（负正得负）
- $3 \times (-2) = -6$（正负得负）

除法同理：$(-6) \div 2 = -3$，$6 \div (-2) = -3$，$(-6) \div (-2) = 3$。

#### “负负得正”的直观理解

为什么两个负数相乘会得到正数？可以试着从几个角度理解：

1. **方向反转**：把负号看作“掉头”。正数表示面向右，乘以 -1 就掉头向左（变成负数）。再乘以 -1 再掉头一次，又面向右（变回正数）。连续两次掉头等于没掉头，所以 $(-1)\times(-1)=1$。
2. **债务的债务**：减掉一笔债务等于增加财富。比如“减去 (-5 元)”意味着“有人取消了你欠的 5 元债务”，相当于你多了 5 元，所以 $0 - (-5) = 5$。推广到乘法：$(-2) \times (-3)$ 可以解释为“去掉 2 次 3 元的债务”，净得 6 元。
3. **分配律的一致性**：为了保证乘法分配律对负数也成立，必须规定负负得正。例如 $(-1) \times (1 + (-1)) = (-1) \times 0 = 0$，分配得 $(-1)\times 1 + (-1)\times (-1) = -1 + ?$，要使和为 0，? 必须是 1。所以 $(-1)\times(-1)=1$。

初学者不需要全部掌握，选择自己最容易接受的一个即可。

### 运算顺序与括号

- 先乘除，后加减；有括号先算括号内。
- 注意负号与减号的区别。遇到 $(-3)^2$ 与 $-3^2$ 的区别：前者是 $(-3)\times(-3)=9$，后者是 $-(3\times3)=-9$。括号决定负号是否参与平方。

## 负数的历史与哲学小谈

负数在人类历史上曾被长期排斥。古埃及、古希腊的数学家只接受正数。古希腊认为“数”对应线段长度，线段不能比“没有”还短。

中国是最早使用负数的文明之一。《九章算术》（公元1世纪）中用红色算筹表示正数，黑色算筹表示负数，并提出“正负术”——正是负数加减法的规则。

印度数学家婆罗摩笈多（7世纪）将负数解释为“债务”，正数为“财产”，并系统地给出了负数的运算规则。

欧洲直到15世纪以后才逐渐接受负数，但仍有人称其为“荒谬的数”“虚构的数”。笛卡尔用“虚根”形容负数的方程解。直到19世纪，负数才被完全纳入数系。

> 从哲学上看，负数并不直接描述物理世界中“有多少个物体”，而是描述**相对关系**：方向、盈亏、增减、坐标。这种抽象能力的跃升，为后来的向量、复数、乃至整个现代数学铺平了道路。这也呼应了之前“序数与单位”中提到的“运算的意义取决于类型”——负数让“减法”永远可行，不再需要说“不够减”。

## 小结

引入负数后，整数集（正整数、0、负整数）对加法、减法、乘法封闭——任意两个整数的运算结果仍是整数。但除法不一定：$1 \div 2$ 就不再是整数，而是分数。类似地，负数也可以与分数、小数结合，得到负分数、负小数。

所有这些数——正整数、负整数、零、正分数、负分数、有限小数和无限循环小数——统称为**有理数**。有理数可以写成 $\frac{p}{q}$ 的形式，其中 $p$ 是整数，$q$ 是非零自然数。注意：$q$ 不必是正数（如 $\frac{-2}{3}$ 也是有理数），通常约定分母为正。

在有理数范围内，加减乘除四则运算几乎全部封闭（唯一例外是除以 0 没有意义）。这比整数又进了一步。负数的出现让我们能够用统一的规则处理相反的量，而有理数则让算术运算更加完备——生活中绝大多数买卖、分配、测量都可以用有理数精确描述。

> 负数带来的核心思想是：**用统一的规则覆盖所有情况**。这一思想在后续的数学、物理中无处不在。
