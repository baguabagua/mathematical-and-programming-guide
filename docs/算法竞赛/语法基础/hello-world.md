# Hello, world!

按照惯例，写的第一个程序应该是 "Hello, world!" 

可以直接复制下面的代码。不过初学者建议手打一遍。

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, world!\n";
    return 0;
}
```

将其保存到一个目录下，命名为 `a.cpp`，然后在该目录下打开 cmd，输入命令 `g++ a.cpp -o a`，就可以看到生成了 `a.exe` 这个程序。然后输入命令 `a` 就可以运行程序，看到输出了 `Hello,world!`。

> 此处应该有一个截图。

解释一下这个命令。`g++` 表示运行 `g++` 程序，`a.cpp` 表示处理 `a.cpp` 这个文件，`-o a` 表示指定输出的文件名是 `a`，但是在 Windows 上会自动变成 `a.exe`. 

> 虽然用 IDE（例如 Dev-cpp）可以一键编译运行，不过还是建议你体验一下通过命令行运行程序。

下面详细解释一下这个程序的每一部分。当然，初学者可能没法完全搞懂，这是正常的，不太懂的地方可以先不要太在意，以后会有更深的理解。

```cpp
#include <iostream>
```

引入头文件。这里引入的是 `iostream` 库，其中包含一些输入输出相关的东西。程序后面出现的 `std::cout` 就是这个库中的，如果不引入则不能直接使用。

```cpp
int main() {
    // 暂时忽略中间
    return 0;
}
```

主函数。程序的入口，程序从这里开始执行。初学者可以先将其看成固定的格式。

> 双斜线 `//` 表示注释。每行的双斜线及其之后的部分会被编译器忽略，用来写一些给人看的东西，一般是对代码的说明。
>
> 另外有另一种语法 `/*这里是注释*/` 也是注释，而且可以跨行。
>
> 注释在代码编辑器中一般都会换一个字体颜色，让人能比较明显地看出来。

```cpp
std::cout << "Hello, world!\n";
```

输出语句。这里涉及到比较多知识点：

1. `std::cout` 要与 `<<` 运算符搭配使用，效果是进行输出。实际上能输出各种类型，包括类似上面例子的字符串，也包括数字。另外，`<<` 可以连用。例如 `std::cout << "1+2=" << 1+2 << "\n";` 会输出 `1+2=3`。
2. `"Hello, world!\n"` 是字符串字面量。其中还有个特殊的 `\n`，这是转义字符。虽然写上去占了两个字符的位置，但它实际上是一个字符，表示换行。
3. 分号 `;` 表示一个语句的结束。C++ 中每个语句都必须以分号结尾。

> C++中的字符串字面量实际上有多种，上面例子中的称为窄字符串字面量。窄字符串字面量中有各种转义字符，都以反斜杠开头来表示。比如双引号要用 `\"`，反斜杠要用 `\\`，换行要用 `\n`，而 `\ooo` 或 `\xhh` 可以用八进制或十六进制来表示 ASCII 码意义下的各种字符，例如 `\101` 和 `\x41` 都表示字符 `A`。 还有一些其它转义字符，用得很少，就不介绍了。
>
> 实际上不同系统上换行是不一样的，类 Unix 系统上 `\n` 就是换行，Windows 上是 `\r\n`。但还有另一件事：C++运行时在 Windows 上写文件时会自动将 `\n` 转换为 `\r\n` 写入磁盘，读取时将 `\r\n` 转换为 `\n`。所以在单个程序内读写时用 `\n` 表示换行就可以。另外，比赛中的评测环境一般都是类 Unix 系统。
> 
> 可以通过大语言模型了解一下原始字符串字面量。
