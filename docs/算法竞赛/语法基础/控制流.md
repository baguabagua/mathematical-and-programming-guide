# 控制流

> 介绍 c++ 中的选择与循环结构。
>
> 本文包含大语言模型辅助创作。

## 什么是控制流？

我们之前的程序都是自 main 函数开头开始，从上往下按顺序一句句执行的。但这并不能解决所有问题。

控制流的效果就是改变程序的运行顺序。主要分为两类：选择结构和循环结构。

> 早期的控制流是用 goto 实现的，可以跳转到程序的任意位置。
>
> goto 功能强大，但是充满隐患，会使得代码难以维护。Dijkstra 在 1968 年写出了著名文章 《Go To Statement Considered Harmful》，反对滥用 goto，提倡结构化编程。所谓结构化编程，就是指程序的控制流仅由三种结构构成：顺序结构、选择结构、循环结构。可以证明，只用这三种结构就可以表达出所有的程序。
>
> 现代编程语言仍然没有完全舍弃 goto，goto 在少数场景仍然有用，不过大部分情况下应该避免使用。作为初学者，不需要了解 goto 的使用。掌握结构化编程即可。

## 选择结构

**单分支选择**：

```cpp
if (condition) {
    // 代码块
}
```

其中 `condition` 是 `bool` 类型的值。如果 `condition` 是 `true`，则执行后面代码块内中的代码，否则不执行。

c++ 中不强制要求 `condition` 是 `bool` 类型，如果不是，会自动将其强制转换成 `bool` 类型进行判断。对于整数类型来说，所有非 0 值都会转换为 `true`，只有 0 会转换为 `false`。但**推荐让条件是显式的`bool`类型**。

如果花括号内恰好只有一个语句，则花括号可以省略，但**推荐永远写花括号**。

> 这些代码风格上的推荐都是为了方便代码维护，让代码的意图更清晰，同时避免引入意外错误。

**双分支选择**：

```cpp
if (condition) {
    // 代码块1
} else {
    // 代码块2
}
```

其中 `condition` 是 `bool` 类型的值。如果 `condition` 是 `true`，则执行代码块 1 内中的代码，否则执行代码块 2 内的代码。

**选择嵌套**：

上面双分支选择中的 else 后面可以直接接一个单分支选择或双分支选择，即：

```cpp
if (condition1) {
    // 代码块1
} else if (condition2) {
    // 代码块2
}
// 分割线
if (condition3) {
    // 代码块3
} else if (condition4) {
    // 代码块4
} else {
    // 代码块5
}
```

效果上等价于写到大括号里面：

```cpp
if (condition1) {
    // 代码块1
} else {
    if (condition2) {
        // 代码块2
    }
}
// 分割线
if (condition3) {
    // 代码块3
} else {
    if (condition4) {
        // 代码块4
    } else {
        // 代码块5
    }
}
```

综合例子：判断一个正整数年份是否是闰年。规则是：对于整百年份，400的倍数是闰年，否则不是；对于非整百年份，4的倍数是闰年，否则不是。

```cpp
int year; // 假设年份已经存在这个变量中
bool is_leap; // 结果要存放到这个变量中

if (year % 100 == 0) {
    if (year % 400 == 0) {
        is_leap = true;
    } else {
        is_leap = false;
    }
} else {
    if (year % 4 == 0) {
        is_leap = true;
    } else {
        is_leap = false;
    }
}
```

写法不唯一，例如也可以这样写：

```cpp
int year; // 假设年份已经存在这个变量中
bool is_leap; // 结果要存放到这个变量中

if (year % 100 == 0) {
    is_leap = (year % 400 == 0);
} else {
    is_leap = (year % 4 == 0);
}
```

在学习函数之后，上面的例子可以写成函数，更加清晰。

### 多分支选择：`switch` 语句

当需要根据一个整型表达式的值从多个分支中选择一个执行时，可以使用 `switch` 语句。它比一连串的 `if-else if` 结构更清晰。

```cpp
switch (表达式) {
    case 常量表达式1:
        // 代码块1
        break;
    case 常量表达式2:
        // 代码块2
        break;
    // ...
    default:
        // 默认代码块
        break;
}
```

**执行过程**：
1. 计算 `switch` 后面括号内的**表达式**（必须是整型、字符型、枚举型，或者能隐式转换为这些类型的值）。
2. 将计算结果与每个 `case` 后面的**常量表达式**依次比较（常量表达式必须在编译时能确定值，且各 `case` 值互不相同）。
3. 如果找到匹配的 `case`，则从该 `case` 的代码块开始执行，直到遇到 `break` 语句或 `switch` 结束。
4. 如果没有匹配的 `case`，则执行 `default` 分支（`default` 可以省略，省略后则什么也不做）。

> `break` 的作用是跳出 `switch` 结构。如果省略 `break`，程序会继续执行下一个 `case` 的代码（这称为“穿透”）。故意省略 `break` 有时用于合并多个分支，但容易造成逻辑错误，**除非有明确意图，否则每个 `case` 都应写 `break`**。

**示例**：根据数字输出对应的星期几。

```cpp
int day; // 假设 day 是 1~7 的整数
switch (day) {
    case 1:
        cout << "Monday" << endl;
        break;
    case 2:
        cout << "Tuesday" << endl;
        break;
    case 3:
        cout << "Wednesday" << endl;
        break;
    case 4:
        cout << "Thursday" << endl;
        break;
    case 5:
        cout << "Friday" << endl;
        break;
    case 6:
        cout << "Saturday" << endl;
        break;
    case 7:
        cout << "Sunday" << endl;
        break;
    default:
        cout << "Invalid day" << endl;
        break;
}
```

**利用穿透的合法场景**：多个 `case` 执行相同操作。

```cpp
char grade; // 'A', 'B', 'C', 'D', 'F'
switch (grade) {
    case 'A':
    case 'B':
    case 'C':
        cout << "Pass" << endl;
        break;
    case 'D':
    case 'F':
        cout << "Fail" << endl;
        break;
    default:
        cout << "Invalid grade" << endl;
        break;
}
```

**`switch` 与 `if-else if` 的选择**：
- **适合 `switch`**：判断的条件是**单个整型/字符型变量**是否等于若干离散值。
- **适合 `if-else if`**：判断范围（如 `x > 10`）、浮点数、复杂逻辑（如 `a && b`）。

**综合例子**：简单的计算器。

```cpp
double a, b;
char op;
cin >> a >> op >> b;

switch (op) {
    case '+':
        cout << a + b << endl;
        break;
    case '-':
        cout << a - b << endl;
        break;
    case '*':
        cout << a * b << endl;
        break;
    case '/':
        if (b != 0)
            cout << a / b << endl;
        else
            cout << "Division by zero" << endl;
        break;
    default:
        cout << "Unknown operator" << endl;
        break;
}
```

> 注意：`switch` 只能做相等性判断，无法直接处理除法中的零检查，因此上面例子在 `case '/'` 内部仍然需要 `if` 语句。这也说明了 `switch` 的局限性——它不能取代所有 `if-else if`。

## 循环结构

循环结构用于重复执行一段代码，直到某个条件不满足为止。C++ 提供了三种循环语句：`while`、`do-while` 和 `for`。

### `while` 循环

```cpp
while (condition) {
    // 循环体
}
```

先判断 `condition`（`bool` 类型），若为 `true`，则执行循环体，执行完后再次判断 `condition`，如此重复，直到 `condition` 为 `false` 时退出循环。如果一开始 `condition` 就是 `false`，则循环体一次也不执行。

与 `if` 类似，如果循环体只有一个语句，花括号可以省略，但**推荐永远写花括号**。

### `do-while` 循环

```cpp
do {
    // 循环体
} while (condition);
```

先执行一次循环体，再判断 `condition`。若为 `true`，则再次执行循环体，如此重复；若为 `false`，则退出。因此 `do-while` 循环**至少会执行一次循环体**。

注意 `while (condition);` 结尾的分号不能省略。

> `do-while` 循环实践中很少使用到。

### `for` 循环

`for` 循环将初始化、条件判断、循环变量更新集中在一起，结构清晰。

```cpp
for (初始化语句; 条件表达式; 迭代表达式) {
    // 循环体
}
```

执行流程：
1. 执行**初始化语句**（只执行一次）。
2. 计算**条件表达式**，若为 `false` 则退出循环；若为 `true` 则进入第 3 步。
3. 执行循环体。
4. 执行**迭代表达式**（通常是更新循环变量）。
5. 回到第 2 步。

> 实际上 `while` 循环和 `for` 循环很容易互相翻译。

**示例**：三种方式计算 1 到 100 的和。

```cpp
int sum = 0;
int i = 1;
while (i <= 100) {
    sum += i;
    i++;
}
// 循环结束后 sum = 5050, i = 101
```

```cpp
int sum = 0;
int i = 1;
do {
    sum += i;
    i++;
} while (i <= 100);
```

```cpp
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
// 循环结束后 sum = 5050，变量 i 仅在循环内有效（因为定义在初始化语句中）
```

> 初始化语句中定义的变量（如 `int i = 1`）作用域仅限于 `for` 循环内部。如果需要在循环外使用循环变量的最终值，应将该变量定义在循环外部。

`for` 循环的三个部分都可以为空：
- 省略初始化语句：例如循环变量已在外部定义。
- 省略条件表达式：相当于条件永远为 `true`，形成无限循环。
- 省略迭代表达式：将更新放在循环体内。类似 `while` 循环的写法。

实际上对初始化语句和迭代表达式的功能也没有要求，你甚至可以这么写：

```cpp
int sum = 0;
int i = 1;
for (; i <= 100; sum += i, i++) {}
```

但是这样写不太好，代码意图不明确，不利于别人或将来的你读懂，也增加了乱中出错的可能。推荐 `for` 循环的迭代表达式就只用于修改循环变量。如果不需要每轮结束时修改循环变量，就优先用 `while` 循环。

### 循环嵌套

一个循环的循环体内包含另一个循环，称为循环嵌套。

**示例**：打印九九乘法表。

```cpp
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        cout << j << "×" << i << "=" << i * j << "\t";
    }
    cout << endl;
}
```

### 控制循环的语句：`break` 和 `continue`

- **`break`**：终止循环。
- **`continue`**：跳过本轮循环进入下一轮。对于 `while` 和 `do-while` 直接进入下一次循环的判断，对于 `for` 先跳到迭代表达式，然后再判断。

处于循环嵌套中时，它们都只影响当前所处的最内层循环。

**示例**：查找第一个能被 7 整除的数。

```cpp
int arr[] = {3, 5, 14, 21, 8};
int target = -1;
for (int i = 0; i < 5; i++) {
    if (arr[i] % 7 == 0) {
        target = arr[i];
        break;  // 找到后立即退出循环
    }
}
```

**示例**：输出 1 到 10 之间的奇数（跳过偶数）。

```cpp
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;  // 跳过 cout 语句
    }
    cout << i << " ";
}
// 输出：1 3 5 7 9
```

> 在 `while` 循环中使用 `continue` 时要小心：如果 `continue` 之前没有更新循环变量，可能导致条件永远为真，造成无限循环。例如：
> ```cpp
> int i = 0;
> while (i < 10) {
>     if (i % 2 == 0) continue;  // 错误！i 没有更新，死循环
>     i++;
> }
> ```

### 无限循环

有时我们需要一个永不退出的循环，可以用以下写法：

```cpp
while (true) {
    // 循环体
}

// 或
for (;;) {
    // 循环体
}
```

在 OI 中，对拍程序会这么写。也可能是配合 `break` 在某个条件满足时退出。

### 综合例子：判断素数

输入一个大于 1 的正整数，判断它是否为素数（质数）。

```cpp
int n;  // 假设 n 已输入且大于 1
bool is_prime = true;

if (n == 2) {
    is_prime = true;
} else {
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            is_prime = false;
            break;
        }
    }
}
```
