## A+B Problem

入门问题。输入两个数 $A$, $B$，输出它们的和 $A+B$。

一般会对这两个数有一定的限制条件。例如都是整数且满足 $-10^9\leq A, B\leq 10^9$.

这里还是直接给出一个标准的程序，再解释。

```cpp
#include <iostream>

int main() {
    int a, b;
    std::cin >> a >> b;
    int c = a + b; // 等价于 int c; c = a + b;
    std::cout << c; // 也可以直接写 std::cout << a + b, 这里为了教学新设了一个变量
    return 0;
}
```

类似上一节课，将其保存到一个目录下，命名为 `a.cpp`，然后在该目录下打开 cmd，输入命令 `g++ a.cpp -o a`，就可以看到生成了 `a.exe` 这个程序。然后输入命令 `a` 就可以运行程序。然后再输入两个整数，例如 `3 5`，然后换行。就可以看到程序输出了 `8` 并自动结束运行。

> 此处应该有一个截图。

这里顺便介绍一下通过重定向操作符进行文件输入输出。新建一个文本文件，命名为 `input.txt`，内容修改为 `3 5`。然后在 cmd 中输入命令 `a < input.txt`，可以看到程序直接输出了 `8` 然后结束运行。这里 `< input.txt` 的作用就是将 `input.txt` 作为命令的输入。类似地，可以用 `> output.txt` 来重定向文件的输出。输入命令 `a < input.txt > output.txt`，可以看到程序什么都没有输出就直接退出了，但是新建了文件 `output.txt`，点进去会看到内容是 `8`.

## 变量

**变量** 是一块有名字的内存空间，用来存储数据。你可以把它想象成一个带有标签的盒子，盒子里可以放不同数值。

### 变量定义

定义变量的语法：`类型 变量名;` 或者 `类型 变量名 = 初始值;`

```cpp
int x;          // 定义了一个 int 类型的变量 x，此时 x 的值不确定（不要使用它）
int y = 5;      // 定义 y 并初始化为 5
int a, b, c;    // 同时定义多个同类型的变量，用逗号隔开
int d = 1, e = 2; // 同时定义并初始化
```

变量名（标识符）只能由字母、数字、下划线组成，且不能以数字开头。不能与 C++ 的关键字（如 `int`, `return`, `main` 等）重名。

### 变量赋值与初始化

- **初始化**：在定义变量时给定一个初始值。未初始化的局部变量其值是随机的（垃圾值），使用它会导致未定义行为。
- **赋值**：定义后修改变量的值。使用 `=` 运算符。

```cpp
int a = 10;   // 初始化
a = 20;       // 赋值
int b;        // 未初始化
b = 30;       // 赋值
```

> 强烈建议在定义变量时就初始化，避免遗忘导致错误。

## 基本数据类型

C++ 提供了许多内置类型，算法竞赛中常用的有：

| 类型 | 关键字 | 常见大小（字节） | 取值范围（简略） |
|------|--------|----------------|------------------|
| 整型 | `int` | 4 | $-2.1\times10^9$ ~ $2.1\times10^9$ |
| 长整型 | `long long` | 8 | $-9.2\times10^{18}$ ~ $9.2\times10^{18}$ |
| 无符号整型 | `unsigned int`, `unsigned long long` | 同有符号 | 非负数范围翻倍 |
| 字符 | `char` | 1 | ASCII 码，通常为 $-128$ ~ $127$ |
| 布尔 | `bool` | 1 | `true`(1) 或 `false`(0) |
| 浮点型 | `float` | 4 | 约 $10^{-38}$ ~ $10^{38}$，6 位有效数字 |
| 双精度浮点型 | `double` | 8 | 约 $10^{-308}$ ~ $10^{308}$，15 位有效数字 |

> 竞赛中，整数一般用 `int`，如果题目数值范围可能超过 $2\times10^9$ 就用 `long long`。浮点数用 `double` 足够，`float` 精度太低容易出错。
>
> 可以用 `sizeof(类型)` 或 `sizeof(变量)` 查看实际占用的字节数，例如 `std::cout << sizeof(int);`

### 整数类型的选择

对于大多数题目，记住：
- 范围约 $[-2\times10^9, 2\times10^9]$ 以内 → `int`
- 超出或不确定 → `long long`
- 无负数且范围更大 → `unsigned long long`

> 使用 `long long` 时字面量加 `LL` 后缀，如 `10000000000LL`。

### 字符与布尔

- **字符**：用单引号括起来，例如 `'A'`, `'1'`, `'\n'`（转义字符）。字符在内存中存储的是其 ASCII 码，可以和整数互相转换。
- **布尔**：只有两个值 `true`（真，转为整数为 1）和 `false`（假，转为整数为 0）。常用在条件判断中。

## 输入与输出（IO）

算法竞赛中最常用的输入输出是 `std::cin` 和 `std::cout`，定义在 `<iostream>` 中。

### 基本用法

- `std::cin >> 变量;` 从标准输入读取一个值存储到变量中。可以连续读取：`std::cin >> a >> b;` 相当于先读 a 再读 b（空格、换行分隔）。
- `std::cout << 值;` 输出值到标准输出。可以连续输出：`std::cout << "hello" << 123 << '\n';`

```cpp
int age;
std::cin >> age;
std::cout << "年龄是：" << age << std::endl;   // std::endl 输出换行并刷新缓冲区
```

> `std::endl` 除了换行还会强制刷新缓冲区，比 `'\n'` 慢。竞赛中建议用 `'\n'` 换行。

### 处理输入直到文件尾

当题目没有明确给出输入个数时，常常需要读到文件尾：

```cpp
int x;
while (std::cin >> x) {
    // 处理 x
}
```

### 加快输入输出（重要！）

默认的 `cin/cout` 为了兼容 C 标准 IO 效率较低。在算法竞赛中，经常添加以下两行来提速：

```cpp
std::ios::sync_with_stdio(false);
std::cin.tie(nullptr);
```

> 加上这两行后，不能混用 `printf/scanf` 和 `cin/cout`，并且多线程程序要小心。绝大多数竞赛题都可以这样用。
