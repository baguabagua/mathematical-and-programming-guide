## A+B Problem

入门问题。输入两个数 $A$, $B$，输出它们的和 $A+B$。

一般会对这两个数有一定的限制条件。例如都是整数且满足 $-10^9\leq A, B\leq 10^9$.

这里还是直接给出一个标准的程序，再解释。

```cpp
#include <iostream>

int main() {
    int a, b;
    std::cin >> a >> b;
    int c = a + b; // 等价于 int c; c = a + b;
    std::cout << c; // 也可以直接写 std::cout << a + b, 这里为了教学新设了一个变量
    return 0;
}
```

类似上一节课，将其保存到一个目录下，命名为 `a.cpp`，然后在该目录下打开 cmd，输入命令 `g++ a.cpp -o a`，就可以看到生成了 `a.exe` 这个程序。然后输入命令 `a` 就可以运行程序。然后再输入两个整数，例如 `3 5`，然后换行。就可以看到程序输出了 `8` 并自动结束运行。

> 此处应该有一个截图。

这里顺便介绍一下通过重定向操作符进行文件输入输出。新建一个文本文件，命名为 `input.txt`，内容修改为 `3 5`。然后在 cmd 中输入命令 `a < input.txt`，可以看到程序直接输出了 `8` 然后结束运行。这里 `< input.txt` 的作用就是将 `input.txt` 作为命令的输入。类似地，可以用 `> output.txt` 来重定向文件的输出。输入命令 `a < input.txt > output.txt`，可以看到程序什么都没有输出就直接退出了，但是新建了文件 `output.txt`，点进去会看到内容是 `8`.

## 变量

变量必须先**声明**（定义）后使用。定义变量的语法：

```cpp
类型 变量名;              // 未初始化，值不确定（不要直接使用）
类型 变量名 = 初始值;     // 初始化
类型 变量名1, 变量名2;    // 同时定义多个
```

```cpp
int a;            // 未初始化
int b = 5;        // 初始化为 5
int x, y = 10;    // x 未初始化，y 初始化为 10
```

根据定义位置，分为**局部变量**和**全局变量**：

- **局部变量**：定义在函数（包括 `main`）或块 `{}` 内部，只在当前作用域有效。**不会自动初始化**，未初始化时值是随机的。
- **全局变量**：定义在所有函数外部，从定义处到文件末尾都有效。**会被自动初始化为 0**（`bool` 为 `false`，指针为 `nullptr`）。

```cpp
#include <iostream>

int global = 100;   // 全局变量，显式初始化
int global2;        // 全局变量，自动初始化为 0

int main() {
    int local;      // 局部变量，未初始化（危险！）
    std::cout << global2; // 输出 0
    return 0;
}
```

> 竞赛中常用全局变量开大数组，因为它们被放在静态存储区，不会爆栈，且自动清零很方便。

## 整数类型

算法竞赛中最常用的整数类型有四个：`int`，`unsigned int`，`long long`，`unsigned long long`。

| 类型 | 通常位数 | 取值范围（补码） |
|------|---------|----------------|
| `int` | 32 | $-2^{31}$ ~ $2^{31}-1$（约 $-2.1\times10^9$ ~ $2.1\times10^9$） |
| `unsigned int` | 32 | $0$ ~ $2^{32}-1$（约 $0$ ~ $4.3\times10^9$） |
| `long long` | 64 | $-2^{63}$ ~ $2^{63}-1$（约 $-9.2\times10^{18}$ ~ $9.2\times10^{18}$） |
| `unsigned long long` | 64 | $0$ ~ $2^{64}-1$（约 $1.8\times10^{19}$） |

C++ 标准没有强制规定这些类型的具体位数，但当前主流平台（Windows / Linux / macOS）上，`int` 就是 32 位，`long long` 就是 64 位。竞赛中可以放心使用。

> 如果数值可能超过 $2\times10^9$，请直接用 `long long`。  
> 注意 `int` 和 `long long` 的字面量：`10` 是 `int`，`10LL` 才是 `long long`。

### 补码知识

计算机用**补码**表示有符号整数。补码的好处是加法和减法可以用同一套电路。  
对于 $n$ 位补码，范围是 $[-2^{n-1},\ 2^{n-1}-1]$。我们可以从**同余**的角度理解：

- 无符号整数 $u$ 对应的有符号整数值 $s$ 满足 $s \equiv u \pmod{2^n}$，并且 $s$ 落在上述范围内。  
  例如 $32$ 位下，$4294967295\equiv -1 \pmod{2^{32}}$，所以 `(int)4294967295` 的值是 `-1`。

### 重命名类型

`long long` 名字太长，我们可以用 `typedef` 或 `using` 给它起一个短名字：

```cpp
typedef long long ll;
using i64 = long long;
using u64 = unsigned long long;
```

之后就可以写 `ll a;` 了。

### 算术运算

整数支持 **加 (`+`)、减 (`-`)、乘 (`*`)、除 (`/`)、取模 (`%`)**。

```cpp
int a = 10, b = 3;
int sum = a + b;      // 13
int diff = a - b;     // 7
int prod = a * b;     // 30
int quot = a / b;     // 3（整数除法，向零截断）
int rem = a % b;      // 1（余数）
```

注意：
- 除法 `/`：如果两个操作数都是整数，执行整数除法（丢弃小数部分）。`10 / 3 = 3`，`-10 / 3 = -3`。
- 取模 `%`：只能用于整数，结果符号与被除数相同：`-10 % 3 = -1`。
- 除法或取模的**除数为 0** 会导致程序崩溃。

> 越界时：无符号整数自动模 $2^n$，有符号整数溢出是未定义行为（通常也会模 $2^n$，但不要依赖）。  
> 常见错误：`int a = 1e9, b = 2e9; int c = a + b;` 会溢出，应当用 `long long`。

## 浮点类型

`float`（单精度，32 位，约 6 位有效数字）和 `double`（双精度，64 位，约 15 位有效数字）。竞赛中**一律使用 `double`**，`float` 精度太低容易出错。

浮点数通常遵循 IEEE 754 标准（不必深究）。支持加、减、乘、除。

```cpp
double x = 5.0, y = 2.0;
double add = x + y;   // 7.0
double sub = x - y;   // 3.0
double mul = x * y;   // 10.0
double div = x / y;   // 2.5
```

> 注意浮点数比较不能直接用 `==`，因为精度问题。通常用 `fabs(a - b) < 1e-9`。

## 布尔类型

`bool` 只有两个值：`true`（真，转为整数 1）和 `false`（假，转为整数 0）。

逻辑运算：
- **与** `&&`：`a && b`，两者都为真时结果为真。
- **或** `||`：`a || b`，至少一个为真时结果为真。
- **非** `!`：`!a`，真变假，假变真。

```cpp
bool p = true, q = false;
bool r1 = p && q;   // false
bool r2 = p || q;   // true
bool r3 = !p;       // false
```

### 逻辑短路

`&&` 和 `||` 遵循短路规则：  
- `a && b`：如果 `a` 为假，不再计算 `b`（因为结果已经确定为假）。  
- `a || b`：如果 `a` 为真，不再计算 `b`。  

利用短路可以安全地写出如下代码：

```cpp
int *p = nullptr;
if (p != nullptr && *p == 10) {   // 不会解引用空指针
    // ...
}
```

## 字符类型

`char` 用于存储单个字符，大小为 1 字节。实际上存储的是该字符的 ASCII 码（0~127），可以当作小整数使用。

```cpp
char ch = 'A';
std::cout << ch;          // 输出 A
std::cout << (int)ch;     // 输出 65
ch = ch + 1;              // 现在 ch 是 'B'
```

ASCII 码中：`'0'` ~ `'9'` 对应 48~57，`'A'`~`'Z'` 对应 65~90，`'a'`~`'z'` 对应 97~122。

处理汉字：一个汉字在 Windows 下通常占 2 字节（GBK），在 Linux 下占 3 字节（UTF-8）。**竞赛中一般不直接处理汉字**。

## 强制类型转换

语法：
- C 风格：`(类型)表达式`
- C++ 风格：`static_cast<类型>(表达式)`

```cpp
double pi = 3.14159;
int ipi = (int)pi;                     // 3，截断
int ipi2 = static_cast<int>(pi);       // 同样 3
double x = 5, y = 2;
double result = static_cast<double>(x) / y;   // 2.5，否则整数除法得 2
```

**隐式转换**：不同类型进行运算或赋值时，编译器会自动转换（小范围向大范围，整型向浮点型，`bool` 向整数等）。

```cpp
int a = 3.14;          // double → int，得到 3（警告）
double b = 5;          // int → double，得到 5.0
bool c = 42;           // 非零 → true
int d = true;          // true → 1
```

> 隐式转换可能带来意料之外的错误，建议必要时使用显式转换。

## 赋值运算

**赋值** `=`：将右侧表达式的值赋给左侧的变量。

```cpp
int a;
a = 5;                 // 正确
int b = a + 3;         // 初始化（不是单纯的赋值）
a + 1 = 5;             // 错误！左侧不是变量
```

右侧表达式的类型会通过隐式转换与左侧匹配。

复合赋值运算符：`+=`, `-=`, `*=`, `/=`, `%=` 等。`a += 3` 等价于 `a = a + 3`。

## 表达式与语句

**表达式**是由变量、常量（包括 `const` 常量和字面量）、运算符连接而成的式子，并且会**产生一个值**。

```cpp
42                  // 字面量表达式，值是 42
x                   // 变量表达式，值是 x 当前的值
x + y               // 算术表达式，值是两者的和
a = 5               // 赋值表达式，值是 5（赋的值）
b = (a = 5)         // 赋值表达式，值是 5
std::cout << x      // 也是表达式，值是 std::cout 本身（不太常用）
```

每个表达式都有**类型**。例如 `3 + 5` 的类型是 `int`，`x < y` 的类型是 `bool`。

> 严格来说，C++ 中几乎所有东西都是表达式（除了声明等）。初学者只需知道：表达式能算出值。

**语句**是以分号 `;` 结尾的代码片段。一个表达式加上分号就变成了**表达式语句**。

```cpp
int a;          // 声明语句（不是表达式）
a = 5;          // 表达式语句（赋值表达式 + 分号）
3 + 5;          // 合法但无意义，计算了值然后丢弃
;               // 空语句
```

**复合语句（块）**：用 `{ ... }` 将多条语句括起来，在语法上视为一条语句。函数体、循环体、条件分支都用到块。

```cpp
int main() {
    int x = 1;
    {
        int y = 2;          // y 只在这个块内有效
        x = x + y;
    }   // y 在此销毁
    // y = 3;               // 错误，y 不可见
    return 0;
}
```

**作用域**：变量从定义点开始，到所在块结束为止可见。块内可以定义与外部同名的变量（会遮蔽外部）。

```cpp
int a = 10;
{
    int a = 20;        // 内部 a 遮蔽了外部的 a
    std::cout << a;    // 输出 20
}
std::cout << a;        // 输出 10
```

## IO（输入输出）

使用 `<iostream>` 中的 `std::cin` 和 `std::cout`。

- `std::cin >> 变量` 读取一个值（按空格/回车分隔）。
- `std::cout << 值` 输出。

```cpp
#include <iostream>

int main() {
    int a, b;
    std::cin >> a >> b;          // 连续读取
    std::cout << a + b << '\n';  // 输出和并换行
    return 0;
}
```

它们可以处理上述所有基本类型：`int`, `long long`, `float`, `double`, `char`, `bool`。另外，cout 可以输出字符串字面量，我们上一节看到过。

> `std::cin` 是 `std::istream` 类型的对象，`std::cout` 是 `std::ostream` 类型的对象。`<<` 和 `>>` 是被重载的运算符，表达式 `std::cout << x` 的返回值是 `std::cout` 自身，因此可以链式 `<<`。
>
> 对 `bool` 类型，`cin >> flag` 会读入整数（0 得 false，非 0 得 true），`cout << flag` 默认输出 0 或 1。可以用 `std::boolalpha` 输出 `true` / `false`。

### 控制浮点数输出格式

要保留固定小数位数，使用 `<iomanip>` 中的 `std::fixed` 和 `std::setprecision`：

```cpp
#include <iostream>
#include <iomanip>

double x = 3.1415926;
std::cout << std::fixed << std::setprecision(2) << x << '\n';   // 输出 3.14
```

- `std::fixed` 表示用定点小数格式（不用科学计数法）。
- `std::setprecision(2)` 表示小数点后保留 2 位。

### 读取到文件尾

当输入数据个数未知时，可以：

```cpp
int x;
while (std::cin >> x) {
    // 处理 x
}
```

`std::cin >> x` 返回 `std::cin` 本身，而 `std::cin` 在读取失败或遇到 EOF（文件尾）时会被转换为 `false`，循环结束。

> 原理：`std::cin` 重载了 `operator bool`，在流状态良好时返回 `true`，否则 `false`。

### 加快输入输出

默认的 `cin/cout` 为了兼容 C 标准 IO 效率较低。在算法竞赛中，在 `main` 开头加上以下两行：

```cpp
std::ios::sync_with_stdio(false);
std::cin.tie(nullptr);
```

- `sync_with_stdio(false)` 关闭 C++ 流与 C 标准流的同步，大幅提高速度。
- `cin.tie(nullptr)` 取消 `cin` 与 `cout` 的绑定，避免每次 `cin` 前刷新 `cout`。

> 使用这两行后，**不能混用** `printf` / `scanf` 与 `cin` / `cout`，否则可能出错。多线程程序也需要小心。竞赛题中几乎可以放心使用。
