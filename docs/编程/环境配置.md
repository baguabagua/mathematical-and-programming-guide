# 什么是环境配置？

用编程语言写好的东西，称为源代码，实际上只是一个文本文件，并不能在任何一个计算机上直接运行。想要运行需要一定的外部环境。具体来说分为两种：

1. 编译型语言。需要外部程序（称为编译器）将其编译（可以理解为翻译）成一个可以直接执行的程序。然后可以直接执行编译得到的程序。
2. 解释型语言。需要通过运行一个外部程序（称为解释器）来运行。

C++ 是编译型语言。编译器有多家，竞赛中广泛使用的是 g++.

环境配置的一部分是把编译器或解释器放在容易使用的位置。

环境配置的另一部分是为了写代码时的体验更好。前面说过，源代码实际上是文本文件，所以直接用原生的文本编辑器（如 Windows 上的记事本、写字板）写也是可以的，但是体验会不太好。有一些专门为写代码优化过的文本编辑器，称为代码编辑器，在文本编辑器的基础上增加了一些功能，例如语法高亮，自动补全等。更重度的是 IDE（集成开发环境），包括代码编辑器、编译器、调试器和图形用户界面等工具。

# 配置什么环境？

这里只介绍 Windows 系统上的，面向算法竞赛的推荐选项。如果是其它系统或其它需求，可以询问大语言模型或询问他人。

## Dev-C++

Windows 平台的轻量级 C/C++ IDE，功能简洁，适合用于教学。

也是 CSP-J/CSP-S/NOIp 考场默认提供的选项之一。

更多信息可以参考 https://oi-wiki.org/tools/editor/devcpp/

> 一般而言，Dev-C++ 5.x 均为 Orwell Dev-C++．其最后一次更新于 2015 年，版本为 5.11．

考场上提供的一般也是这个版本。下载链接：https://sourceforge.net/projects/orwelldevcpp/

记得修改编译选项。添加 `-std=c++14 -O2 -Wl,--stack=104857600`

代码补全和主题可以根据自己的需要配置。

## VSCode

强大的代码编辑器。通过插件也可以实现 IDE 的各种功能。

https://oi-wiki.org/tools/editor/vscode/ 给出了一些竞赛推荐使用的插件。不用插件也可以。

一般来说，需要另外安装编译器。推荐 MinGW-w64. 可以在 https://sourceforge.net/projects/mingw-w64/files/mingw-w64/mingw-w64-release/ 找到最新的 zip 文件下载。然后解压到合适的位置并把 `bin` 目录添加到系统 PATH. 也可以通过 MSYS2 安装。有问题多问大语言模型。

> MinGW-w64 是一个 Windows 上的 C/C++ 开发环境/工具链，其中包含了 g++ 这个 c++ 编译器命令。

# Windows 系统的基本知识

## 文件系统

**文件**。Windows 中各种东西都以“文件”的形式存在，包括文档、图片、程序。文件可以进行复制、剪切、粘贴、重命名。

**文件后缀名（扩展名）**。用于区分文件类型。典型的如 `.exe` 是可执行文件，`.jpg`, `.png` 是图像，`.txt` 是文本文件，`.cpp` 是 c++ 源代码。**推荐取消勾选“隐藏已知文件类型的扩展名”**。

> 实际上文件类型不完全靠后缀名区分，而是靠文件本身的编码区分。尽管如此，**不要在你不确定后果的情况下修改文件的后缀名**。

**文件夹**。在电脑上的任何一个位置，你可以创建文件夹。文件夹里可以有任意多个文件。特别地，文件夹里也可以有其它文件夹。文件夹的作用是便于文件的检索，就像把所有东西分门别类整理好要比平铺在一个桌子上容易找东西一样。

> 技术上讲，文件夹是一种特殊的文件。
>
> 文件夹不能直接或间接包含自身。如果尝试制造悖论，例如，B 是 A 的子文件夹，然后尝试把 A 剪切粘贴到 B 内部，此时会报错，提示“目标文件夹是源文件夹的子文件夹”。

**本地磁盘与“此电脑”**（旧版本称为“我的电脑”）。磁盘可以看成一些最大的文件夹，所有其它文件夹都必须直接或间接放在某个磁盘中。所有的磁盘又在此电脑中。此电脑中不能直接存放文件或文件夹，必须通过磁盘。

> 文件资源管理器中显示的本地磁盘的数量并不一定与真实的硬盘数量相同。旧电脑普遍使用的是 HDD 硬盘，会把一个盘分成多个区来使用，这些分区会分别称为 C 盘，D 盘，E 盘等。现在普遍使用的 SSD 硬盘已经不推荐进行分区，也就是一块硬盘的话就只有一个分区，也就是 C 盘。也有可能电脑上真的装了两个硬盘，那就各占一个分区，分别是 C 盘和 D 盘。

**文件路径**。类似于地址。描述你家的地址要先说在哪个国家，然后是哪个省、哪个市、哪个县（区）……一直到足够精确定位为止。描述文件的位置也是同样的道理，要先说在哪个磁盘，然后说在这个磁盘的哪个文件夹下，再说在这个文件夹的哪个子文件夹下……一直到文件直接所在的文件夹，然后说出文件名。

例：`C:\projects\讲课\mathematical-and-programming-guide\README.md` 是在 C 盘的 projects 文件夹下的 讲课 文件夹下的 `mathematical-and-programming-guide` 文件夹下的 `README.md` 文件。可以看到 Windows 的路径中文件夹之间以反斜杠 `\` 连接，磁盘与文件夹之间以 `:\` 连接。

上面的称为绝对路径。

文件夹内和磁盘最顶层也称为目录。

**快捷方式**。

**常见的路径**:

* `C:\Users\你的用户名`，注意在中文版的图形界面一般显示的不是 `Users` 而是 `用户`。这个路径下有很多预设的特定目的的文件夹，包括桌面、下载、图片、文档、音乐等。你可以随意使用它们，但推荐按照名称去使用。另外会有一些 `.` 开头的文件或文件夹。**不要在你不确定后果的情况下修改或删除它们**。
* `C:\Windows` 系统文件夹，`C:\Program Files, C:\Program Files(x86)` 程序文件夹。**不要在你不确定后果的情况下修改或删除它们**。

## 命令行

> 更多相关内容可以参考 https://oi-wiki.org/tools/cmd/ 和 https://oi-wiki.org/tools/compile-debug/

Windows 上的命令行界面有两个，cmd（命令提示符）比较古老也比较简单。PowerShell 比较新也比较复杂。初学者先学会简单使用 cmd 就行。

cmd 的打开方式：
1. 快捷键 win+R 打开运行，输入 `cmd` 后回车，会打开 cmd。默认工作目录是 `C:\Users\你的用户名`
2. 在文件资源管理器的路径栏输入 `cmd` 后回车，会打开 cmd，工作目录就在当前打开 cmd 的位置。

初步掌握的命令：
1. `cd 路径` 把工作目录切换到输入的路径。相对或绝对路径都可以。
2. `D:` 把工作目录切换到 D 盘。不同的盘之间是不能通过 cd 切换的，必须通过这种方式。
3. `dir` 查看当前目录内的所有文件和目录。这里会看到 `.` 和 `..` 这两个隐藏目录。
4. `可执行文件名` 执行文件。或者说运行程序。

还有很多没有介绍的命令，有些会在后面介绍到，大部分不会。感兴趣可以自行学习。
